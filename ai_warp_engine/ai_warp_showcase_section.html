⚡ AI WARP ENGINE — v6.4.25 Full-canvas LENS inversion

Public-domain visual synthesizer and audio-reactive Canvas effects suite. The app-matched browser edition and Windows release share the v6.4.25 LENS FX pipeline.

Release highlights

  1. v6.4.25 — Full-canvas inversion: grayscale plus true inversion and Hue rotation run after the complete composition, including LENS frames, init artwork, RAUM · X-R showcase slides and easter eggs. Freeze-frame exports preserve the live canvas filters.
  2. v6.4.24 — LENS controls and playlist automation: bottom-dock B&W/Hue sliders activate paired voices with live previews; playing or importing saved playlists starts background extraction.
  3. v6.4.23 — Playlist vault: protected featured playlist, visible playable entries, resilient XML feed extraction and direct-playback fallback.
  4. 34 independent voices: 17 retained core rails plus 17 isolated GC#(3) R3 rails; machine presets guarantee coverage of every R3 factory.
  5. YouTube Warp Bus (new): the live YouTube feed is drawn directly onto the effects pipeline — all 29 warp modes deform #ytWarpShell and all 34 voices feed a cumulative on-video filter chain. v6.4 browser display capture also accepts a tab, app window, or full screen; the independent microphone input and YouTube iframe/Canvas feed stay available. Hotkeys: M mic, Y featured playlist, E Ear mode, and N display capture.
  6. Ghost Protocol R3/v11: DIA, SPECTRUM, CRT, PLASMA, LED; channel splits, Old-Soul echo, scan/warp, CRT/LED texture, and confluence bursts.
  7. V-Sync R3/v11: Scanphasing, Color Harmony, Sharp; tracking, tears, roll, phosphor texture, held OFF rails, mode-specific levels, and a lock.
  8. Automation: Auto Glitch, Continual Rand, Timed Auto, Auto Masters, Soft-Eye/Crescendo, and visual/audio ear integration select core/R3 factory confluence pairs and drive R3 targets and bursts.
  9. Canvas/WebGL core: voices render on Canvas/WebGL; the lone SVG usage is the compositor-level Warp Lens (feTurbulence → feDisplacementMap) displacing YouTube pixels per-frame — display-only, no JS readback.
  10. 29 Warp modes, media studio controls, YouTube knowledgebase, local media, microphone input, procedural synth, presets, and frame export.

R3 controls

Ghost cycle: OFF → DIA → SPECTRUM → CRT → PLASMA → LED → OFF. OFF retains the rail; Ghost Null clears it.

V-Sync cycle: OFF → SCANPHASING → COLOR HARMONY → SHARP → OFF. OFF retains the last live rail; V-Sync Null clears it.

Manual sliders provide a grace period before automation resumes. V-Sync stores independent rails for each active method, and user presets store those levels.
