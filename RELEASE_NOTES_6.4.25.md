# AI WARP ENGINE 6.4.25 — Full-canvas LENS inversion

Release 6.4.25 replaces the B&W overlay wash with an image-wide compositor pass and applies Hue/Color Cycle to the complete rendered picture.

## Highlights

- **True B&W inversion:** the final composed image is converted to grayscale and inverted, rather than merely receiving a white difference-blend overlay.
- **Complete LENS coverage:** the final pass includes captured YouTube LENS frames, initialization art, the Raum X-R artwork showcase, captions, and the reversed-Я/signature easter eggs.
- **Full-image Hue spectrum:** Hue/Color Cycle now rotates the complete canvas image, using the existing slider, voice levels, and persisted setting.
- **Freeze-frame parity:** exported screenshots apply the same final canvas filter as the live view.
- **Browser YouTube path:** the in-page Warp Bus applies the same full-strength grayscale inversion to its cross-origin YouTube display.
- **Preserved prior work:** v6.4.24 slider pairing, live previews and automatic playlist extraction remain included.
