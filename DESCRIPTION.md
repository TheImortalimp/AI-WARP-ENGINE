## GitHub About description

AI WARP ENGINE: Windows visual synthesizer with 34 glitch voices, 29 warp effects and YouTube LENS. v6.4.37: Glitch Hardened & FX Fixed, continuous FX, offline AVI conversion and no external-browser launches.

## Project summary

AI WARP ENGINE v6.4.37 is a Canvas-based visual performance app for Windows
10/11 x64, with a matching browser edition. Layer generative visuals, local
media, YouTube or shared-display frames with independently controlled glitch
voices, warp modes, R3 Ghost Protocol/V-Sync and audio-driven automation.

The app includes 80 machine presets, saved user presets, Milkdrop-inspired
feedback, built-in synth grooves, four original RAUM X-R tracks, voice/master
locks, full-viewport B&W/Hue controls and Canvas PNG freeze frames.

Version 6.4.37 smooths FX transitions and sustains, adds offline conversion for
unsupported local video/audio, and restricts app navigation and native controls.
Remote app scripts, release debugging and external-browser launches are disabled.
Existing Windows system-pointer protections and accessibility remain. The HUD
reads `v6.4.37 · Glitch Hardened & FX Fixed`.

The installer requires UAC elevation and applies cursor/theme/sound policy
hardening; it is unsigned. Browser-only usage does not apply Windows policies
and uses display sharing for readable YouTube pixels.
