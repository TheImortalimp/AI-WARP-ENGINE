# AI WARP ENGINE 6.4.22 — Voice FX tuning and automation

Release 6.4.22 adds fine-grained B&W inversion and Hue/Color Cycle controls, with randomized FX settings and a variable Auto Glitch roll during board and preset randomization.

## Highlights

- **Bottom-dock FX tuning:** adjust B&W inversion strength and Hue/Color Cycle offset with dedicated sliders, separate locks and a manual **ROLL FX** action.
- **Automation-aware randomization:** **RANDOMIZE** and every preset auto-cycle reroll unlocked B&W/Hue settings. Each also independently rolls Auto Glitch ON/OFF with 50/50 odds.
- **Persistent settings:** both FX values and their lock states persist locally; user presets store their FX values.
- **Core / GC#(3) confluence:** the two voice banks remain separate and individually controllable. Automation continues to choose complementary pairs, with subtle renderer differences retained.

Run `AI-WARP-ENGINE-6.4.22-x64-setup.exe` on Windows 10/11 x64. It installs per-user without administrator access.
